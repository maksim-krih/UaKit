Для розробників

Усе, що є на цій сторінці, доступне як безкоштовна відкрита бібліотека UaKit (ліцензія MIT) для JavaScript/TypeScript і C#/.NET, без залежностей.

JavaScript / TypeScript

npm install uakit
import { moneyToWords } from 'uakit';

moneyToWords(1250.5);
// Одна тисяча двісті п’ятдесят гривень 50 копійок
uakit на npm

C# / .NET

dotnet add package UaKit
using UaKit;

MoneyToWords.ToWords(1250.50m);
// Одна тисяча двісті п’ятдесят гривень 50 копійок

Часті питання

Як правильно писати суму прописом у документах?

Гривні пишуть словами, а копійки зазвичай цифрами: «Одна тисяча двісті п’ятдесят гривень 50 копійок». Слово «гривня» узгоджується з числом: одна гривня, дві гривні, п’ять гривень. Числівники «один» і «два» перед гривнею, копійкою та тисячею стають жіночого роду: «одна», «дві». Якщо потрібно, копійки теж можна записати словами, для цього є перемикач «Копійки словами».

Як округлюються копійки?

Сума округлюється до двох знаків після коми, половина копійки округлюється вгору: 0,995 → одна гривня 00 копійок. Рахунок ведеться в десятковій арифметиці, тому немає похибок на кшталт 1,005 → 1,00.

Як перевіряється код ЄДРПОУ?

Код ЄДРПОУ має 8 цифр, остання з них контрольна. Її обчислюють як зважену суму перших семи цифр за модулем 11, причому ваги залежать від діапазону коду. Якщо контрольна цифра не збігається, у коді помилка: зайва, пропущена чи переставлена цифра.

Що можна дізнатися з ІПН (РНОКПП)?

Перші п’ять цифр РНОКПП — це кількість днів від 31 грудня 1899 року до дати народження, дев’ята цифра непарна в чоловіків і парна в жінок, десята контрольна. Тому з правильного номера можна визначити дату народження і стать.
